# Traivo

Traivo är en AI-driven SaaS-plattform för fältserviceplanering, byggd för nordiska företag inom avfallshantering, fastighetsservice och teknisk drift.

Plattformen består av två delar:

- **Traivo One** – planerings- och kontorsverktyget med AI-driven schemaläggning, ruttoptimering, kundportal, fakturering och rapporter.
- **Traivo Go** – mobil fältapp för tekniker med dagens uppdrag, navigation, digitala protokoll, signering och offline-stöd.

## Teknisk stack

- React 18 + Vite + TypeScript
- Tailwind CSS + shadcn/ui
- Lovable Cloud (Supabase) för backend, auth och edge functions
- Lovable AI Gateway (Gemini) för konversations-AI

## Utveckling

```bash
npm install
npm run dev
```
